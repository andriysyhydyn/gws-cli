Privacy policy

Last updated: 19 October 2026

gws cli is a personal tool. Its only user is its owner, Andriy Syhydyn, who uses it with his own Google account.

What data it accesses

When the owner signs in, the tool can access his Gmail, Google Calendar, Google Drive, Docs, Sheets, Slides and Tasks, plus his basic profile (name and email address). It only acts on commands the owner runs himself.

How data is stored

Sign-in credentials are stored encrypted on the owner's own computer. Data read from Google is processed on that computer and is not stored on any server run by this tool.

Sharing

No data is sold, shared with third parties or used for advertising. The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
